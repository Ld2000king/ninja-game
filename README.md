# Ninja Wars (מחווה)

משחק קרבות צבאות נינג'ה בהשראת Ninja Warz. רץ מקומית בדפדפן, בלי שרת ובלי שום תשלום.

## הפעלה
- לחיצה כפולה על `start-game.bat`, או:
- `npm install` ואז `npm run dev`. הדפדפן ייפתח בכתובת http://localhost:5173

## איך המשחק בנוי
- **העיר:** מסך הבית. בה נמצאים הדוג'ו, חנות הנשקים, הבלון שמוביל למפת הקרבות ומקדש הזימון.
- **נינג'ות:** כל נינג'ה ייחודי: שם, מראה, חיים ונזק בסיס ותכונה. הנדירות קובעת את טווח הנתונים.
- **חגורות:** לבנה → צהובה → כתומה → ירוקה → כחולה → סגולה → חומה → שחורה. מבחן חגורה דורש ניסיון קרב וזהב, וכל חגורה מכפילה חיים ונזק.
- **נשקים:** קונים בחנות ומציידים איזו נינג'ה שרוצים. הנשק מוסיף נתונים, וסוג הנשק קובע יכולת מיוחדת.
- **קרב:** בכל סיבוב הצבאות קופצים לענן קרב. בסוף הסיבוב השורדים חוזרים, ומי שנגמרו לו החיים נופל בדרך.

## מבנה הקוד
| קובץ | מה יש בו |
|---|---|
| `src/data/rarity.js` | נדירויות, חגורות ותכונות |
| `src/data/weapons.js` | כל הנשקים וסוגי הנשקים (היכולות) |
| `src/data/ninjas.js` | מחולל נינג'ות (שם, מראה, נתונים) |
| `src/data/monsters.js` | זומבים ובוסים |
| `src/data/stages.js` | מפת העולם: 4 אזורים × 4 שלבים |
| `src/game/stats.js` | חישוב הנתונים הסופיים (בסיס × חגורה × תכונה + נשק) |
| `src/game/battle.js` | מנוע הקרב עם ענן הקרב |
| `src/game/save.js` | שמירה מקומית, דוג'ו, חנות, זימון |
| `src/art/*.js` | כל הציורים בקוד: דמויות, נשקים, זירות, מפה ועיר |
| `src/main.js` | המסכים |
